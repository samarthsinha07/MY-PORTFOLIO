## 🚀 Getting Started

To run the project locally, clone the repository:

```bash
git clone https://github.com/samarthsinha07/Portfolio.git
cd Portfolio
```

Install dependencies according to the package manager and configuration files included in the repository, then start the development server using the scripts defined in `package.json`.
